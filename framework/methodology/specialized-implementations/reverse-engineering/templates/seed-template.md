# Reverse Engineering Seed Template (default)

> Copy this to `twtty/reverse-engineering/seed/seed.md` and name the repository, the audience, and
> the purpose. What is produced, and how, is defined by the specialization.

```markdown
## What I Want To Build

I want to reverse engineer the following repository: [folder name]

Audience: [who the resulting knowledge is for]

Purpose: [the objective it supports]

## Done Looks Like

The audience has a reliable, evidence-based understanding of the repository,
sufficient to accomplish the stated purpose.
```
